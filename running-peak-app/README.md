# Running Peak

เช็กลิสต์ซ้อมวิ่ง 12 สัปดาห์ สไตล์การ์ตูน 2D จากเพซเบา 6:00 สู่เป้าหมายเพซ 4:00 ติ๊กการซ้อมได้ 36 ครั้ง เปิดได้ทั้งคอมและมือถือ และติดตั้งลงมือถือแบบแอป (PWA) ได้

## แผนรอบนี้

- เริ่มจันทร์ 2 พ.ย. 2026 ซ้อมจันทร์ พุธ ศุกร์ ส่วนวันเสาร์แล้วแต่โอกาส
- เป้ารอบ 12 สัปดาห์: 5K 23:45 (เพซ 4:45)
- เพซวิ่งเบา 6:00-6:30, วิ่งยาว 6:15-6:45, วิ่งหนัก 5:00 และ 4:45

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บทั้งหมด รวมฟอนต์ สไตล์ และสคริปต์ไว้ในไฟล์เดียว |
| `manifest.webmanifest` | ข้อมูลสำหรับติดตั้งเป็นแอป |
| `sw.js` | เก็บไฟล์ไว้ในเครื่องเพื่อให้เปิดแบบออฟไลน์ได้ |
| `icon-*.png`, `apple-touch-icon.png` | ไอคอนแอป |
| `.nojekyll` | บอก GitHub Pages ให้เผยแพร่ไฟล์ตามเดิม |

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `running-peak` แบบ Public
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ระดับบนสุดของ repository
3. ไปที่ Settings > Pages แล้วตั้ง Source เป็น Deploy from a branch เลือก `main` และ `/ (root)`
4. รอสักครู่ เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/running-peak/`

## ติดตั้งลงมือถือ

- Android: เปิดลิงก์ใน Chrome แล้วเลือกติดตั้งแอป
- iPhone: เปิดลิงก์ใน Safari แล้วเลือกเพิ่มไปยังหน้าจอโฮม

## การเก็บข้อมูลและการซิงก์

การติ๊กเก็บอยู่ในเบราว์เซอร์ของแต่ละเครื่องด้วย `localStorage`

ถ้าต้องการให้มือถือกับคอมตรงกัน ให้กดปุ่ม **ซิงก์มือถือกับคอม** ท้ายหน้าเว็บ แล้ววาง GitHub token ที่มีสิทธิ์ gist เท่านั้น ทำแบบเดียวกันบนทุกเครื่อง ข้อมูลจะเก็บใน Gist แบบ Secret ชื่อ `running-peak.json` ในบัญชี GitHub ของคุณ แต่ละเครื่องซิงก์เมื่อเปิดหน้าเว็บ หลังติ๊กประมาณ 1 วินาที ทุก 20 วินาทีระหว่างเปิดหน้าไว้ และเมื่อแตะข้อความสถานะข้างปุ่มซิงก์ ถ้าติ๊กคนละข้อพร้อมกัน ระบบจะรวมให้ ถ้าเปลี่ยนข้อเดียวกัน ระบบจะยึดการเปลี่ยนล่าสุด

token เก็บอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น ไม่อยู่ใน repository

การอัปเดตทันทีใช้ [ntfy.sh](https://ntfy.sh) เป็นตัวส่งสัญญาณ เมื่อเครื่องหนึ่งบันทึกลง Gist จะส่งข้อความสั้นๆ ที่ไม่มีข้อมูลการติ๊กไปยังช่องลับซึ่งสร้างจาก token แล้วเครื่องอื่นที่เปิดหน้าไว้จะดึงข้อมูลจาก Gist ทันที ถ้า ntfy.sh ใช้ไม่ได้ ระบบจะกลับไปซิงก์ทุก 20 วินาทีตามเดิม

## การแก้ไข

- วันเริ่มแผนอยู่ที่ `START` และตารางอยู่ที่ `PLAN` ใน `index.html`
- `sw.js` โหลดหน้าเว็บจากเน็ตก่อนเสมอ และใช้สำเนาในเครื่องเมื่อออฟไลน์ ถ้าแก้ไอคอนหรือ manifest ให้เปลี่ยนเลข `C` ใน `sw.js` ด้วย
